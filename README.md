How to Compile and Run : 

To compile and run the playlist, open a terminal in the folder that contains Playlist.java. The first command compiles the code, and the second starts the program. You need a JDK installed (Java 8 or newer) for javac to work.

Menu options :

Add Song
Delete Song
Search Song
Display Playlist
Play Song
Next Song
Previous Song
Count Total Songs
Exit

1. Add Song: Asks for a number, name, and duration, then adds the song to the end of the list (if the number isn't already used and the duration is above zero).

2. Delete Song:Removes the song with the number you type, and if that song was playing, the player moves to a neighbor.

3. Search Song:Looks for the song with the number you type and shows its name and duration if it's found.

4. Display Playlist:Prints every song in order, showing its position, number, name, and duration.\

5. Play Song:Finds the song with the number you type and makes it the current song.

6. Next Song:Moves to the song after the current one, or says you're already at the last song.

7. Previous Song:Moves to the song before the current one, or says you're already at the first song.

8. Count Total Songs:Counts how many songs are in the playlist and shows the total.

9. Exit: Ends the program and says goodbye.
